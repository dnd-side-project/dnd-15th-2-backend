# Production Java 작업 지침

production Java 수정이나 코드 적합성 검토 전에 [Java 관례](../../../docs/harness/JAVA_CONVENTIONS.md)를 읽고 적용한다.
상세 규칙은 원본 문서에 유지한다. 관련 도메인 결정은 [문서 선택표](../../../docs/harness/TASK_DOCUMENT_ROUTING.md)를 따른다.
테스트 변경에는 해당 테스트 하위 지침도 적용한다. [root 계약](../../../AGENTS.md)의 역할·승인·소유 파일·필수 검증 조건을 유지한다.
