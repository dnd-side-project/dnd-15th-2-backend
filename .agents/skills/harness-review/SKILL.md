# PM and Safety Review

Read `AGENTS.md`, `TASK.md`, `agents/pm-reviewer.md`, Jira, GitHub Issue, diff,
reports, and check results. Report scope mismatches, convention failures,
evidence gaps, secret/destructive risks, required changes, and an
approve/request-changes/blocked recommendation. Do not edit implementation while
acting as reviewer.
