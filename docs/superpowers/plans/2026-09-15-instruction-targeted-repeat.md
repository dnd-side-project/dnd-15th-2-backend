## 고정 범위

B/X는 Run 1과 동일한 source seed, 지침, 요청, TASK, 승인 테스트 계획, Sol/high, 최종 oracle을 사용한다. 새 중립 사본과 새 세션에서 Run 2/3을 실행한다. 기존 수정된 작업트리나 정답 이력은 복사하지 않는다. 실행 전 seed 파일 hash 일치와 runner 안전 gate를 독립 확인한다. Q 보완안은 이 반복의 지침에 섞지 않는다.

## 품질과 해석

각 실행의 제품 변경과 동일 oracle 결과를 독립 검토한다. 기존 리뷰 pack에서 보조 검사 결과 본문이 빠졌던 한계를 반복하지 않도록 결과 요약과 exit code 근거를 함께 제공한다. 검증을 통과하지 않은 실행은 토큰 절감 성공으로 해석하지 않는다.

B/X 각각 3개의 Before/After 관측값, 짝별 변화율, 중앙값과 범위를 제시한다. Run 1이 효과가 커서 선택된 사실과 중단·환경 차이를 명시한다. n=3을 통계적 확증으로 표현하지 않으며 전체6과제에 일반화하지 않는다. 캐시 입력·비캐시 입력·출력·시간을 별도로 보고한다. 반복 준비와 분석 비용은 측정 CLI 비용과 구분한다.
