## Before와 After 후보

Before는 사용자 확정 commit `4aa58b8b5cad727372e7dac1dd254099b62243b8`의 지침 85파일이다. C1은 기존 공통 정합성 수정·테스트 경로 지침과 v2의 11파일 변경을 합친 비공개 후보이며 94파일이다. Before 대비 추가9·수정19·삭제0이고 두 manifest로 추적한다. 비교 대상은 전체 개선 묶음 C0/C1이다.

C1의 원문 정책447개는 대상의 완전한 줄 구간 SHA-256으로 모두 일치했다. 신규 링크23개와 11파일 변경 범위도 독립 검토를 통과했다. 초기 부분 문자열 매칭이 정책3개의 잘못된 좌표를 허용해 해당 결과를 기각·보존하고 완전 일치 검사로 교체했다. root 크기25,006→19,350바이트는 정적 파일 크기이며 토큰 절감률이 아니다. 후보는 원본 저장소의 운영 지침에 적용하지 않았다.

## 실패와 재실행 기록

F의 초기 fixture 생성 및 시간 형식 오류, missing-class 컴파일 실패는 의미적 결함 탐지와 구분해 보존했다. B/X에서 전체 검사 명령이 겹친 실행과 XML 작성 실패를 보존했다. XML 실패 원인은 UNKNOWN이며 병렬 실행이 원인으로 입증됐다고 주장하지 않는다. 중복 실행 종료 후 직렬 실행이 통과했다. X의 후속 형식 검사 실패도 수정·재검사 이력과 함께 보존했다.

B는 구조 강제 테스트 제거와 뒤이은 필터 검사로 Gradle 입력이 바뀌었고, 이전 전체 XML이 별도 보존되지 않아 최종 전체 검사를 다시 실행했다. 최종 전체 XML·컴파일 산출물 해시를 별도 보관한 뒤 추가 필터 검사를 중단했다. 이 준비 비용은 실제 비교 실험의 토큰 절감 결과가 아니다.

## 격리와 남은 실행 조건

비공개 `offline-001`에 여섯 역사적 소스를 각각 새 Git seed와 로컬 bare origin으로 만들었다. 원본 저장소 커밋·push가 아니다. seed 초기화의 hooksPath 설정은 해당 사본에만 적용했다. 참고 정답과 oracle가 들어간 준비 사본은 그대로 모델 입력으로 사용하지 않는다. 평가용 C0/C1 사본은 정답·미래 Git 이력·평가표 없이 다시 export하고 쌍별 동일성을 확인해야 한다.

환경 파일22개의 준비 전후 해시와 CLI 해시는 같았다. 이는 오프라인 준비 중 안정성만 확인하며 기존 POST_ENVIRONMENT_DRIFT 원인을 해결한 증거가 아니다. 기존 수집기 self-test17개는 통과했지만 새 6과제 실행·Q 다중 대화의 종단 검증은 아니다.

실제 평가 전 남은 항목은 깨끗한 쌍별 입력 생성, 다중 대화·쓰기 과제 수집기 검증, 모델 실행 환경 drift 판정, 구체적 실행 계약·예산 확정이다. 17세션·입력6M·출력120k·150분 제안은 이번 단계에서 실행하지 않았다. 새 벤치마크 CLI 호출은0회이며 준비 에이전트 작업 비용과 구분한다. 토큰 절감률과 After-v1 도입 적합성은 아직 판정할 수 없다.
